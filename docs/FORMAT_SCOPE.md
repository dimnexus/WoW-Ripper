# Format scope

WoW Ripper focuses on World of Warcraft client data useful to addon authors and asset researchers.

## Storage

- Battle.net .build.info
- CASC local indexes/data archives
- TACT encoding/root metadata
- BLTE content containers

## Data tables

- DBC legacy headers
- DB2 family headers
- Modern WDC-family tables

## Art

- BLP textures
- M2 models
- WMO world models
- ADT/WDT world terrain

## Audio

- OGG
- MP3
- other client-delivered audio formats as encountered

## Development references

Implementation is based on public format documentation and independent observation. Public technical references include Blizzard's description of CASC and community-maintained format documentation such as wowdev/Warcraft Wiki. No third-party extractor source is vendored into this project.
